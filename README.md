<h1>WebScrapper for Prices on websites for materials</h1>

<h3> Currently only has uses for Amazon, Lowe's, and Home Depot</h3>

<h4>How to Use</h4>
  
<p>
  Create an account on Google Cloud and create a project. Create a service account. Generate a key from this service in JSON format. Save the file as credentials.json and put it in the same folder as the project. 
We will also need a normal Firefox profile to simulate the user the bot is using. Either import from a different browser to Firefox and then copy and paste the profile into the directory as "firefox_profile" or change FIREFOX_PROFILE to the proper path.

Lastly, name a file the urls.txt, this is where you will input the links to the products 1 by 1.
</p>
